## Herramientas de ingeniería

- Para GeoGebra se implementó el cargador oficial con Álgebra y barra de entrada. Las tres actividades iniciales abren Gráfica. Intersección, cálculo simbólico, producto e inversa trabajan en Classic. El idioma del applet es inglés para reproducir los comandos mostrados. [Integración](https://geogebra.github.io/docs/reference/en/GeoGebra_Apps_Embedding/) · [Matrices](https://geogebra.github.io/docs/manual/en/Matrices/) · [Solve](https://geogebra.github.io/docs/manual/en/commands/Solve/) · [Intersect](https://geogebra.github.io/docs/manual/en/commands/Intersect/) · [Determinant](https://geogebra.github.io/docs/manual/en/commands/Determinant/) · [Licencia](https://www.geogebra.org/license)
- canalPLC documenta CADe SIMU, su uso educativo y el mecanismo para obtener las actualizaciones. La academia enlaza al autor y ofrece prácticas de escritorio con alternativa táctil. [Distribución](https://canalplc.blogspot.com/p/blog-page_14.html) · [CADe SIMU](https://canalplc.blogspot.com/p/cadesimu.html)
- La ruta de dibujo distingue AutoCAD general, el toolset Electrical para Windows, las aplicaciones web y móvil y el acceso educativo sujeto a elegibilidad. [Education](https://www.autodesk.com/education/edu-software/overview) · [Electrical](https://www.autodesk.com/products/autocad/included-toolsets/autocad-electrical) · [Web y móvil](https://www.autodesk.com/products/autocad-web/overview)
- Las prácticas de electrónica comparan modelos ideales con simuladores web. [Falstad](https://www.falstad.com/circuit/) · [Wokwi](https://docs.wokwi.com/) · [Tinkercad](https://www.tinkercad.com/circuits)
- Packet Tracer se emplea para Ethernet, direccionamiento y topologías. Los modelos didácticos locales cubren configuración Modbus, tramas y cronogramas de E/S. [Cisco Packet Tracer](https://www.netacad.com/cisco-packet-tracer) · [Descargas y plataformas](https://www.netacad.com/packet-tracer-download)
- Los complementos industriales se presentan con su edición, requisitos y alcance. Se distingue OpenPLC histórico del editor web documentado en Autonomy Edge. [CODESYS](https://store.codesys.com/en/codesys.html) · [OpenPLC y Autonomy Edge](https://autonomylogic.com/docs/) · [OpenPLC v3](https://github.com/thiagoralves/OpenPLC_v3) · [Factory I/O](https://docs.factoryio.com/getting-started/) · [LibreCAD](https://librecad.org/)

Cada ficha de la biblioteca contiene el enlace a la documentación y un ejercicio. La comprobación HTTP de enlaces y la verificación funcional de GeoGebra se ejecutan por separado.
